# 2.1.0
Essa atualização foca totalmente em inovações, reorganização e adaptação. Agora, **BreVM se torna um projeto independente**.
ProtoIndigo continua usando a arquitetura Stack da BreVM, apesar de haver uma arquitetura híbrida incluindo registradores.
Essa atualização traz diversas **funcionalidades novas**, e conteúdo para **expressões matemáticas**. Além de 
receber pequenas **otimizações**, **padronização de erros** e novas **toolchains**, para garantir a **melhor experiência**.

Aproveite as releases de embedding do ProtoIndigo! Estamos felizes em anunciar o primeiro protótipo de Stantard Library do ProtoIndigo.

A partir desta versão (2.1), ProtoIndigo segue com changelogs mais organizados, e com o desenvolvimento **[aberto da documentação
do interpretador]()**.

## Changed

### Operation
O Orquestrador Operation, foi refatorado. mantendo estado, melhor debugging e uma api mais
limpa, usável e estável.

- Tratamento de erros com excessões. mantendo estado na REPL e outros casos.
- Error melhorados
> Adicionado mais destaque, clareza e padronização nos erros.
> incluindo as fases da operação ao lançamento de um erro.
- Adicionado fases.
> Como `Running`, `Created` `Stopped` etc.

### CLI 
- Novo comando: ´repl´
> Inicia explicitamente a REPL

### AST
- AST melhorada, e otimizada.

### Parsing
- Parser melhorado, limpo e reorganizado.
- Parsing para novas expressões.

### Tokenizer
- Tokenizer refatorado e aprimorado.
- Novos tokens: `CTX`, `GO`, `TO`, `INCREMENT`, `DECREMENT`, `_NULL`, `INTEGER`, `DOUBLE`, `TEMPLATE`
- Novo tipo de token: CTX
> Um token que representa partes do código, que dependem de um contexto.
- Suporte a comentários
- Suporte a símbolos
- Suporte a números doubles, hex.
- Suporte a keyword null
- Suporte a strings processadas
- Suporte a strings não processadas
- Adicionado lexema

### Codegen
- Adicionado suporte para BreVM 0.0.2
- Adicionado suporte para BreVMR 1
- Adicionado suporte para novas intruções e expressões.
- Adicionado suporte para RuntimeValues

## Release

### Standard Library
Nova standard library em fase de testes e desenvolvimento!

- `_BETA_STD_FIRSTARG`
> Retorna o primeiro argumento passado após o caminho do arquivo na CLI.

- `_BETA_STD_VERSION`
> Retorna a versão do interpretador

### Keywords
- Keyword `const` removida.
- Keyword contextual `label` adicinada.
- Keyword `go` adicinada.
- Keyword `to` adicinada.
- Keyword `pre` adicinada.

### ProtoIndigo
- Adicionado suporte a comentários.
```bre
// Olá! isso é um comentário. sou ignorado pelo Tokenizer. 
```
---

- Novas instruções para incremento, e decremento de variáveis/constantes do tipo Number.
```bre
new x = 10;
x++; // Equivalent to: x = x + 1
x--; // Equivalent to: x = x - 1
```

---
- Adicionado suporte a expressões via parênteses;
> Expressões entre parênteses isolam uma expressão. dando-a prioridade de resolução ao interpretador.
 
> Não confunda proto com uma função só por causa dos parênteses. proto continua sendo uma instrução,
> e algo como `proto(10, "Hello World!")` resultará em erro.
```bre
new x = 10 - 5 + (100 / 2); // A expressão dentro dos parênteses, será resolvida com prioridade.
```

```bre
proto(10 / 2) // Isso não é uma função. Porém é interpretado normalmente.
```
--
- Adicionada multiplicação implícita;
> A multiplicação explícita que ainda está em fase de testes, faz com que números vindos antes de
> identificadores, ou expressões via parênteses `()`, sejam interpretadas como multiplicação.

```bre
new x = 10;
proto 2x; // Equivalente a: proto 2 * x;
```

```bre
proto 2(10 + 10); // Equivalente a: proto 2 * (10 + 10);
```
---

- Adicionada a instrução `label`
> Utilizada para marcar pontos específicos no código. 
> permitindo que instruções como goto desviem o fluxo de execução da VM para determinado ponto.

```bre
label myhome
```

- Adicionado strings processadas;
> Sendo interpretado para strings com aspas, aspas duplas e strings templates.

```bre
proto "Hello, World! \n by ProtoIndigo"
```

resultado esperado:

```txt
Hello, World!
 by ProtoIndigo
```

Além de escapes como 

```bre
"\n \\ \t"
```

- Adicionado strings sem processamento;
> São strings que não são processadas ao receberem escapes.

```bre
new text = u"Hello, World! \n by ProtoIndigo"; // \n ignorado.
```

resultado esperado:

```txt
Hello, World! \n by ProtoIndigo
```

- Adicionado Hexa Decimais;
> Suporte paraa sintaxe de hexa decimais, sendo compilados para o token INTEGER

```bre
new num = 0x05

proto num; // 5
```

- Adicionado suporte a números decimais

```bre
new altura = 1.87;
```

- Removida a keyword e expressão legada de constantes

Instrução removida:

```bre
new const x = 5;
```

mantendo apenas pela palavra-chave `now`:

```bre
now x = 5;
```

- Nova instrução para instruçoes pré execução:

```bre
pre <statement>
```

para inclusão de arquivos:

```bre
pre include "file.bre"
```

- Nova sintaxe para inclução de scripts bre:

```bre
pre include "file.bre"
```

adicionando a keyword `pre` antes de `include`.
